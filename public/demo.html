How It Works

This chat widget requires customers to enable location services before starting a chat. This helps verify their identity and provides you with valuable customer information.

Try it now! Click the chat button in the bottom-right corner to test the widget.

Integration

Add this single line of code to your website to embed the chat widget:

<script src="https://your-server.com/widget.js"></script>

Or with custom server URL:

<script> window.CHAT_SERVER_URL = 'https://your-chat-server.com'; </script> <script src="/widget.js"></script>
